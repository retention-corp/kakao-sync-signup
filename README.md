# kakao-sync-signup

카카오싱크 간편가입과 카카오톡 채널을 AI 에이전트가 대신 설정해 주는 스킬이에요. 카카오디벨로퍼스 콘솔과 카카오비즈니스를 브라우저로 직접 조작하고, 카카오가 사람에게만 허용하는 순간(로그인, 휴대폰 인증, 동의 버튼)에만 사람을 불러요.

한 번의 카카오 가입으로 서비스가 받는 것: 이름, 전화번호, 이메일, 약관 동의, 광고성 정보 수신 동의, (선택) 카카오톡 채널 친구.

## 언제 쓰나

서비스가 **정식으로 문을 열었을 때** 써요. 가입·로그인·탈퇴가 실제로 돌아가고, 사이트가 완성돼 있어야 해요.

카카오비즈니스는 출시 전 서비스(CBT, OBT, 미완성 사이트)의 비즈니스 채널 심사를 반려해요. 비즈니스 채널이 없으면 간편가입을 켤 수 없어요. 이 저장소의 예시인 가상 제품 auto-fde도 실제로 "[전환 불가-정식 사업 미개시]"로 반려됐어요(`docs/build-log/2026-11-25-auto-fde.md` 27번).

출시 전이라면 스킬은 테스트 앱까지만 가요. 카카오 심사 없이 동의 화면과 약관을 미리 맞춰 둘 수 있어요. 제품을 다 만들기 전에 카카오 설정부터 붙잡지 마세요. 제품이 준비된 뒤 귀찮은 이 작업을 맡기세요.

## 검증한 범위

| 단계 | 상태 |
|---|---|
| 앱 생성, 비즈 앱 전환, 신청 자격 확인, 카카오 로그인, Redirect URI | 실제 실행 |
| 테스트 앱: 동의항목, 개발자 채널, 대표 채널, 약관 3개, 간편가입 | 실제 실행 |
| 약관·처리방침·광고 동의 페이지 작성과 배포, 사전 점검 | 실제 실행 |
| 비즈니스 채널 심사 신청(서류·소명 입력) | 실제 실행, 출시 전 서비스라 반려 |
| 정식 앱의 채널 연결, 간편가입, 개인정보 동의항목 심사 | 아직 실행 못 함(정식 운영 서비스로 확인 필요) |

## 하는 일

1. **처음에 한 번만 물어요.** 앱 이름, 사업자 정보, 사업자등록증 파일, 약관 페이지, 채널 이름과 검색용 ID(나중에 못 바꿈), 테스트 앱을 만들지, 각 단계 승인까지 한 메시지로 받아요. 중간에 "이 서류도 주세요"로 멈추지 않게 하려는 거예요.
2. **사이트부터 점검해요.** 개인정보처리방침에 항목·필수/선택·목적(회원가입)이 있는지, 약관 페이지가 열리는지, 광고 동의 제목이 KISA 기준에 맞는지 `precheck.py`로 확인해요.
3. **콘솔을 설정해요.** 앱 만들기 → 비즈 앱 전환 → 신청 자격 확인 → 채널 만들기·비즈니스 채널 심사 → 앱-채널 연결 → 카카오 로그인·Redirect URI → 대표 채널 → 약관·간편가입 → 개인정보 동의항목 심사.
4. **심사를 한 번에 통과하도록 준비해요.** 카카오 공식 반려 사유 표와 데브톡 카카오 직원 답변 67건, 실제 반려 사례를 점검표로 만들어 신청 전에 돌려요.
5. **캡처를 안전하게 찍어요.** 이름·이메일·사업자번호·키를 가리고 찍고(`clean-shot.mjs`), 글자 인식으로 다시 검사해요(`scan-shots.swift`).

## 사람이 필요한 순간 (보통 5분 안쪽)

- 카카오디벨로퍼스·카카오비즈니스 로그인이 풀려 있을 때 로그인
- 비즈니스 채널 심사의 마지막 확인란([동의])과, 나오면 카카오톡 전자증명서 또는 대표자 휴대폰 인증
- (테스트 앱을 만든 경우) 실제 로그인 시험에서 [동의하고 계속하기]

카카오 심사(채널 연결, 개인정보 동의항목)는 각각 영업일 3~5일이 걸려요. 결과가 나오면 에이전트가 이어서 진행해요.

## 테스트 앱

테스트 앱은 실제 앱과 따로 있는 연습용 앱이에요. 카카오 심사 없이 이름·전화번호까지 받는 동의 화면을 앱 멤버에게만 미리 띄워 볼 수 있어요. 출시 전 서비스이거나 심사 전에 화면을 확인하고 싶을 때 써요. 스킬은 이걸 설명하고 만들지 물어본 뒤, "예"일 때만 만들어요.

## 지키는 원칙

- 승인받지 않은 앱·채널에는 저장·심사 신청을 하지 않아요.
- 실제 가입·탈퇴가 없는 서비스로는 개인정보 동의항목 심사를 신청하지 않아요. 카카오에 허위 자료를 내는 셈이라서예요.
- 앱 키·클라이언트 시크릿은 캡처·보고서·저장소에 남기지 않아요.

## 준비물

- Claude Code 같은 에이전트(이 폴더를 스킬로 읽을 수 있는 것)
- 로그인된 세션을 쓰는 브라우저 자동화 도구. 예시 코드는 ego-browser(ego-lite) 기준이에요.
- macOS(캡처 글자 인식 검사 `scan-shots.swift`가 Vision을 써요), Python 3
